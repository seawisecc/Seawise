Drop your logo file here.

To use your own logo:
1. Save it in this folder as: SeaWise.png
   (or any name — update LOGO_SRC in components/Logo.tsx to match)
2. Open components/Logo.tsx and set:  const USE_IMAGE_LOGO = true;

The logo updates in both the navbar and footer at once.

You can delete this README.txt once your logo is in place.
